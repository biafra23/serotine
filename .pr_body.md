This PR adds the UI integration for creating Safe accounts owned by P-256 hardware-bound keys.

## Changes

### New UI Option
- Added Hardware P-256 account menu option in the Accounts screen's floating action button
- Created HardwareP256 icon in SerotineIcons for the menu item

### API Updates
- Added onCreateHardwareP256 callback parameter to AccountsRoute and AccountsScreen
- Added AppGraph.createHardwareP256AccountViewModel() factory method

### Implementation Details
- The callback creates a CreateAccountViewModel pre-configured for hardware P-256 account creation
- When triggered, it calls startHardwareAccount() which:
  - Generates a new P-256 key from the device's Secure Enclave/StrongBox
  - Derives an Ethereum address from the public key
  - Creates a Safe with both the P-256 derived address AND an EOA as owners (threshold 2-of-2)
  - Adds the account to the wallet

### Testing
- Updated AccountsScreenTest and AccountsScreenPreviews to include new parameter
- All UI desktop tests pass
- Desktop app builds successfully
