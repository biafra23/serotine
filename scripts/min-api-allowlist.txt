# scripts/check_apk_min_api.py: `<referrer-class-prefix> <owner#member>` per
# line, prefix-matched on the referring class, exact-matched on the target.

# A FIRST-PARTY (eth/serotine/*, io/myotis/*) violation NEVER belongs here — fix
# the call instead (.claude/rules/platform.md, "minSdk 29 JDK-API budget"). Third-party entries
# fall into three classes, noted per section:
#   [guarded]  the library probes for the API at runtime and falls back;
#   [dormant]  the code path is not wired/reachable in this app's configuration;
#   [LIVE]     reachable on a normal run at an API level where the app still runs
#              that code — a real crash there, tracked for an upstream fix.
# Regenerate candidates by running the checker with --allowlist /dev/null.
